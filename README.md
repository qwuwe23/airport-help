# 五元机场订阅说明

这是五元机场的公开说明镜像。它提供订阅导入、日常维护和问题定位的快速入口；账户、套餐与订阅链接请始终以[官方用户中心](https://www.5airport.uk/)显示为准。

## 推荐操作顺序

1. 登录[用户中心](https://www.5airport.uk/#/login)，确认账户和订阅状态。
2. 只从账户页面取得订阅链接，并妥善保存，不将链接发布到公开位置。
3. 参阅[设备教程](https://www.5airport.uk/guides)完成导入与首次更新。
4. 使用自己常用的网站或应用测试节点，并准备一条已验证的备用节点。
